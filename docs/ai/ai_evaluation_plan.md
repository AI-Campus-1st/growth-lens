# AI 평가 계획

- 작성일: 2026-11-25 · 담당: 김한승 (평가셋 작성: 모듈 담당자 전원) · 상태: **[제안]**
- **목표 수치(합격 기준)는 베이스라인 측정 후 설정합니다. 지금 수치를 정하지 않습니다.**

## 1. 평가 항목

| 지표 | 정의 | 측정 방법(제안) |
|---|---|---|
| Retrieval relevance | 검색 문서가 질문과 관련 있는가 | 정답 문서 ID 대비 Recall@k / 수작업 판정 |
| Groundedness | 응답 주장이 컨텍스트로 뒷받침되는가 | 문장 단위 근거 대응 수작업 판정 (+보조로 LLM 판정, 교차 검증) |
| Citation accuracy | 인용이 실제로 해당 주장을 지지하는가 | 인용-주장 쌍 판정 |
| Numerical consistency | 응답 수치가 표준 출력 수치와 일치하는가 | **자동 검사**: 응답 내 수치 추출 → 컨텍스트 수치 대조 |
| Hallucination rate | 근거 없는 사실·수치 비율 | 판정된 비지지 주장 수 / 전체 주장 수 |
| Unsupported recommendation | 근거 없는 권고 | 권고별 근거 ID 존재·타당성 검사 |
| Data-mixing violation | 국내·해외 데이터 혼합 서술 | 규칙 기반 + 수작업 |
| Label correctness | 관측/추정/가정/권고/한계 구분이 맞는가 | 수작업 |

## 2. 평가셋
- 위치: `growth-lens-backend/tests/ai/` (형식 W2 확정)
- 구성(제안): 모듈별 질문 + 정답 근거(결과 ID/문서 ID) + 기대 답변 요점
  - 수치 질의 / 개념 질의 / 권고 요청 / **답할 수 없는 질문**(데이터 범위 밖 — 거절 또는 한계 안내가 정답)
- 작성: 각 모듈 담당자가 자기 모듈 질문 작성, 김한승이 통합·검토
- 수량은 킥오프에서 합의 [미정]

## 3. 비교 실험
| 조건 | 설명 |
|---|---|
| B0 | 템플릿 리포트 |
| B1 | 구조화 컨텍스트 + LLM (비-RAG) |
| B2 | B1 + RAG |

- 같은 평가셋으로 B1 vs B2 비교 → RAG 채택 여부 결정
- 결과는 `docs/reports/ai_evaluation_results.md` (생성 예정)에 기록
