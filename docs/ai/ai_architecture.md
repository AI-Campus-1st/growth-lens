# AI 아키텍처

- 작성일: 2026-11-25 · 담당: 김한승 · 상태: **[제안] — 구현 없음, 기술 선택 미정**

## 1. 3계층 책임 분리

| 계층 | 담당 | 하는 일 | 하지 않는 일 |
|---|---|---|---|
| Structured Analytics | SQL / Python (`growth-lens-data/src/modules`, `growth-lens-data/sql/`) | KPI, 통계, 모델 예측, 수치 분석, 검증된 결과 | 자연어 해석 |
| Retrieval | RAG (`growth-lens-backend/src/ai/rag`, `growth-lens-backend/src/ai/retrieval`) | 승인 보고서, 데이터 사전, 지표 정의, 방법론, 검증된 시장 자료 검색 | **정확한 수치 질의 대체 금지** |
| LLM | `growth-lens-backend/src/ai/llm`, `growth-lens-backend/src/ai/prompts` | 해석, 요약, 리포트 서술, 근거 기반 권고, Q&A | **계산 금지**, 근거 없는 권고 금지 |

## 2. 요청 처리 흐름 (개념)

```
사용자 질문 / 리포트 생성 요청
   │
   ├─▶ 의도 분류: 수치 질의 / 개념·방법론 질의 / 권고 요청
   │
   ├─▶ [수치] 표준 출력(manifest + 결과 테이블) 구조화 조회 ──┐
   ├─▶ [개념] RAG 문서 검색 (top-k, 출처 포함) ───────────────┤
   │                                                         ▼
   │                                   컨텍스트 조립 (수치 + 문서 + 메타)
   │                                                         ▼
   │                                   LLM 생성 (인용 필수, 5개 구분 라벨)
   │                                                         ▼
   └──────────────────────────────▶ Guardrails 검사
                                     · 수치 일관성(출력 수치 ⊂ 컨텍스트 수치)
                                     · 인용 존재·정확성
                                     · 국내/해외 데이터 혼합 서술 탐지
                                     · 근거 없는 권고 탐지
                                                         ▼
                                                   응답 / 리포트
```

## 3. 출력 구분 라벨 (필수)
- **관측 사실** (observed) · **모델 추정** (estimated) · **사용자 가정** (assumption) · **권고** · **한계**

## 4. 산출물
| 산출물 | 입력 | 단계 |
|---|---|---|
| 모듈별 AI 브리핑 | 해당 모듈 표준 출력 | 1단계 (비-RAG) |
| Monthly Seller Action Report | M01(김한승)·M03(국내) 중심 + M02(지혜인)·M04는 "방법론 인사이트"로 분리 | 1단계 |
| AI Assistant (Q&A) | 표준 출력 + RAG | 2단계 (평가 통과 시) |

## 5. 데이터 혼합 금지 규칙
- 국내(KR) 결과와 해외(FR/US) 결과를 한 문장에서 같은 판매자·상품·고객에 대한 사실처럼 서술하지 않음
- 리포트에서 해외 결과는 별도 섹션 + 시장 라벨

## 6. 미정
LLM 제공사, 임베딩 모델, 벡터DB, 검색 프레임워크, 오케스트레이션 프레임워크 — 승인 전 설치·선정하지 않음.
