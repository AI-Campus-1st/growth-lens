# 프로젝트 범위 (Scope)

- 작성일: 2026-11-25 · 상태: 초안

## 1. 포함 범위 (In Scope)
| 영역 | 내용 |
|---|---|
| 데이터 | 네이버 DataLab(검색어 트렌드·쇼핑인사이트), 네이버 검색광고 키워드 도구, KOSIS, 기상청·공휴일, Criteo Uplift, The Complete Journey — 각 가용성 검증 후 |
| 분석 | M01~M04 모듈별 분석 MVP와 검증 |
| AI | 근거 기반 요약·브리핑, 월간 리포트, (평가 결과에 따라) RAG 기반 Q&A |
| 플랫폼 | 7개 화면의 MVP, 데이터 출처·한계 라벨링 |
| 문서 | 기획·데이터·아키텍처·AI·회의 문서, 최종 보고서 |

## 2. 제외 범위 (Out of Scope)
- 실제 스마트스토어 판매자 계정 연동, 판매자 개인 매출·고객 데이터 수집
- 크롤링 등 약관 위반 가능성이 있는 수집 (허용 여부 확인 전까지)
- 실제 이익·ROAS 계산 (원가·광고비 데이터 없음) — 사용자 입력 가정 기반 시뮬레이션만 선택적으로
- 실시간 스트리밍, 결제, 회원 관리 등 운영 기능
- 국내외 데이터를 결합한 단일 고객/상품 모델

## 3. 오늘(초기화 단계) 범위
- 기획 문서, 역할, 디렉터리 구조, 협업 규칙, 상위 아키텍처, 데이터 타당성 계획
- **분석 모델·API·RAG·앱 기능 구현은 하지 않음**

## 4. 성공 기준 (정성, 수치 목표는 데이터 검증 후 설정)
- 각 모듈이 표준 출력 계약을 만족하는 검증된 결과를 제출
- 플랫폼에서 모든 결과가 출처·기간·결과 유형과 함께 표시
- AI 출력이 근거 인용과 수치 일관성 평가를 통과 (기준값은 평가 계획에서 확정)
- 범위 축소 시에도 결정 근거가 문서화됨
