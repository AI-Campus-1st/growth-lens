## 1. 개요

**GrowthLens — Commerce & Marketing Intelligence Platform**
네이버 스마트스토어의 소규모 판매자(1~3인 운영, 분석 전담 인력 없음)가 ① 수요 관심도는 오르지만 경쟁 부담이 상대적으로 낮은 상품군을 찾고 ② 마케팅 준비 시점을 정하며 ③ 타게팅 전략을 평가하고 ④ 매출 성과를 진단하도록 돕는 의사결정 지원 플랫폼.

## 2. 문제 정의

| 질문 | 판매자의 고민 | 모듈 |
|---|---|---|
| WHAT | 어떤 상품군을 탐색해야 할까? | M03 Market Opportunity |
| WHEN | 관심도가 오른 뒤 마케팅하면 이미 늦은 게 아닐까? | M01 Marketing Timing |
| WHO | 할인 안 해도 살 고객에게 쿠폰을 주고 있진 않을까? | M02 Promotion Intelligence |
| PERFORMANCE | 어떤 상품·프로모션이 매출에 기여할까? | M04 Revenue Analysis |

## 3. 제약 조건 [확정]
- 팀 4인, 개발 기간 5~8주
- 산업은 패션 / 뷰티 / 식품 / 생활·리빙 중 **1개** 선택 — **[미정]** 데이터 타당성 검증 후 결정
- 실제 판매자 단위 고객·매출 데이터 없음 → 공개 데이터 + 공개 연구 데이터셋 기반

## 5. 모듈 설계 요약

### M01 Marketing Timing — 김한승
- 핵심 질문: "소비자 관심도가 증가한 뒤 마케팅을 시작하는 것은 이미 늦은 것이 아닐까?"
- 기능: 계절성 분석, 검색↔쇼핑 클릭 선후행(lead-lag), 외부 요인(기온·공휴일·시즌 이벤트), 이상 탐지, 관심도 예측, 마케팅 준비 일정 추천
- 방법: STL 분해, 교차상관(CCF), 변화점 탐지, 예측 + Rolling backtesting
- 데이터: 네이버 검색어 트렌드, 쇼핑인사이트, KOSIS 온라인쇼핑동향, 기상청, 공휴일 **[미검증]**
- 한계: 관심도 지표는 **상대 지수**이며 판매량이 아님

### M02 Promotion Intelligence — 지혜인
- 핵심 질문: "할인하지 않아도 구매할 고객에게 쿠폰을 지급하고 있는 것은 아닐까?"
- 기능: 처치/통제 비교, ATE 추정, 증분 효과, Uplift Modeling(S/T-Learner), 전환 예측 기반 vs 업리프트 기반 타게팅 비교, 타게팅 정책 평가
- 평가: AUUC, Qini, Uplift@K, 증분 전환, 독립 holdout
- 데이터: **Criteo Uplift(주, RCT)**, The Complete Journey(보조·관측)
- 한계: 4가지 고객 유형은 **개념적 분류**, 개인의 실제 유형은 관측 불가. 프랑스 광고 데이터 → 국내 판매자에 직접 적용 불가, **방법론 시연** 성격

### M03 Market Opportunity — 김민지 (플랫폼 핵심 모듈)
- 핵심 질문: "수요 관심도는 상승하지만 경쟁 부담은 상대적으로 낮은 상품군은 무엇인가?"
- 프레임워크: **DETECT → DIAGNOSE → RECOMMEND**
  - DETECT: 관심도 성장, MoM/YoY, 급상승 탐지, 성별·연령·기기별 추이
  - DIAGNOSE: 수요 성장, 경쟁 지표, 성장 지속성, 시장 성장, 데이터 신뢰도, Opportunity Score
  - RECOMMEND: 월별 2~3개 기회 상품군 + 정량 근거 + 리스크 + 근거 기반 AI 브리핑
- 데이터: 쇼핑인사이트, 검색어 트렌드, 검색광고 키워드 도구, KOSIS, 상품수·판매자수·가격 분포 **[미검증]**
- 한계: 광고 경쟁도 ≠ 상품 공급 경쟁. 공급 경쟁 데이터를 확보하지 못하면 **"광고 기회 발굴"로 범위 축소** (대안 범위 B). 조건을 충족하는 상품군이 없으면 추천하지 않음.

### M04 Revenue Analysis — 이선진
- 핵심 질문: "어떤 상품이 매출에 기여하고 있으며, 광고와 할인·쿠폰은 구매에 어떤 영향을 미칠까?"
- 기능: 상품별 매출·기여도, 주/월 추이, 수량·구매 빈도, 할인·쿠폰 금액, 프로모션 기간 성과 비교, 성과 진단, (선택) 사용자 입력 원가 기반 이익 시나리오
- 데이터: The Complete Journey (transactions, products, promotions, campaigns, coupons, coupon_redemptions)
- 한계: 미국 식료품 소매 데이터(가구 패널) — 스마트스토어와 채널·국가 다름. 원가·광고비 없음 → 실제 이익·ROAS 계산 안 함.

### M02 ↔ M04 경계 [제안]
| | M02 | M04 |
|---|---|---|
| 질문 | 마케팅이 **추가로** 만든 효과는? 누구를 타게팅? | **관측된** 매출과 프로모션 기간 성과는? |
| 데이터 | Criteo(RCT) 중심 | Complete Journey 중심 |
| 인과 주장 | RCT 기반에서만 | 하지 않음 (기술·비교 분석) |
| 재사용 | — | M02의 검증된 효과 결과를 참조만, 업리프트 파이프라인 중복 구현 금지 |

## 6. 공통 AI 계층 — 김한승
- 구조화 분석 계층(SQL/Python: KPI·통계·예측) → 검색 계층(RAG: 승인된 보고서·데이터 사전·지표 정의·방법론) → LLM 계층(해석·요약·근거 기반 권고·Q&A)
- LLM은 계산기로 쓰지 않음. 정확한 수치 질의는 벡터 검색이 아니라 구조화 조회로 처리.
- 출력은 관측 사실 / 모델 추정 / 사용자 가정 / 권고 / 한계를 구분
- 산출물: 모듈별 AI 브리핑, Monthly Seller Action Report, AI Assistant
- LLM 제공사·임베딩·벡터DB·프레임워크 **[미정]**
- RAG의 실효성은 **비-RAG 베이스라인 대비 평가로 판단** [제안] — [ai_evaluation_plan.md](../ai/ai_evaluation_plan.md)

## 7. 플랫폼 — 김한승

- MVP 후보: Streamlit **[제안, 비확정]**
- 모든 화면에 데이터 출처·시장(국가)·관측 기간·한계·결과 유형 라벨 표기

## 8. 범위 시나리오 [제안]
- **범위 A (목표)**: 4개 모듈 + AI 브리핑 + 월간 리포트 + 통합 플랫폼
- **범위 B (M03 축소)**: 공급 경쟁 데이터 확보 실패 시 M03을 "관심도 성장 × 광고 경쟁도" 기반 광고 기회 발굴로 축소
- **범위 C (최소 MVP)**: M01·M03 국내 파이프라인 + M02·M04 분석 결과 페이지 + 비-RAG AI 브리핑
