## 4. 김한승 업무 과부하 분석 [중요]
김한승은 1개 분석 모듈 + PM + 플랫폼 + AI 계층을 동시에 맡아 **팀에서 가장 큰 일정 리스크**입니다.

완화 방안 [제안 — 킥오프에서 결정]:
1. **M01(김한승) 범위 축소**: MVP = 계절성(STL) + 선후행(CCF) + 준비 일정 추천. 예측·변화점 탐지·외부 요인은 선택(stretch).
2. **공통 수집 이관**: 네이버 DataLab 수집기는 M03(김민지)이 주도, M01은 재사용.
3. **시각화 분산**: 각 모듈 담당자가 차트 사양·프로토타입·표준 출력을 제공하고, 김한승이 공통 화면과 연결합니다. 실제 화면 구현 분담은 프레임워크 결정 시 함께 확정합니다.
4. **AI 단계화**: 1단계 비-RAG 근거 브리핑 → 2단계 RAG는 평가로 필요성이 입증될 때만.
5. **평가 데이터 분산**: 모듈별 평가 질문·정답 근거는 각 담당자가 작성.
6. **부담당(백업) 지정**: §5 배정안 참고.
7. **공공데이터 수집 이관**: M01 외부 요인(기상청·공휴일)과 KOSIS 수집을 이선진에게 이관 (§5).
