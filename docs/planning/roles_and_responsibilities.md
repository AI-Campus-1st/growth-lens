## 4. 김한승 업무 과부하 분석 [중요]
김한승은 1개 분석 모듈 + PM + 플랫폼 + AI 계층을 동시에 맡아 **팀에서 가장 큰 일정 리스크**입니다.

완화 방안 [제안 — 킥오프에서 결정]:
1. **M01 범위 축소**: MVP = 계절성(STL) + 선후행(CCF) + 준비 일정 추천. 예측·변화점 탐지·외부 요인은 선택(stretch).
2. **공통 수집 이관**: 네이버 DataLab 수집기는 M03(김민지)이 주도, M01은 재사용.
3. **시각화 분산**: 각 모듈 담당자가 자기 화면 컴포넌트를 직접 개발 → 김한승은 레이아웃·라우팅·공통 라벨만.
4. **AI 단계화**: 1단계 비-RAG 근거 브리핑 → 2단계 RAG는 평가로 필요성이 입증될 때만.
5. **평가 데이터 분산**: 모듈별 평가 질문·정답 근거는 각 담당자가 작성.
6. **부담당(백업) 지정** [미정]: 예) 플랫폼 백업 1인, AI 평가 백업 1인.
